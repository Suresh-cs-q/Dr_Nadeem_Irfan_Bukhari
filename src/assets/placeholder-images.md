# Placeholder Images

For a complete website, you should add the following images to the `/public` directory:

1. `hero-bg.jpg` - Background image for the home page hero section
2. `research-bg.jpg` - Background image for the Research Interests page header
3. `academics-bg.jpg` - Background image for the Academics page header
4. `professional-bg.jpg` - Background image for the Professional Experience page header
5. `publications-bg.jpg` - Background image for the Publications & Projects page header
6. `conferences-bg.jpg` - Background image for the Conferences & Workshops page header
7. `contact-bg.jpg` - Background image for the Contact page header

You can use free stock images from websites like:
- [Unsplash](https://unsplash.com)
- [Pexels](https://pexels.com)
- [Pixabay](https://pixabay.com)

Look for academic/education/research-related images with good contrast for text overlay.
