# Dr. Irfan - Academic Portfolio Website

This is a modern, responsive academic portfolio website built with React for Dr. Irfan. It features 7 different pages to showcase academic achievements, research interests, publications, and more.

## Pages

1. **Home** - Landing page with a hero section and highlights
2. **Research Interests** - Detailed information about research areas and projects
3. **Academics** - Educational background, teaching experience, and mentorship
4. **Professional Experience** - Academic positions, industry experience, and skills
5. **Publications & Projects** - Publications, research projects, books, and chapters
6. **Conferences & Workshops** - Past and upcoming events, organized events
7. **Contact** - Contact information, contact form, and FAQs

## Setup

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm (v6.0.0 or higher)

### Installation

1. Clone the repository
   ```bash
   git clone <repository-url>
   cd sir_irfan
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Build for production
   ```bash
   npm run build
   ```

## Customization

### Content

All content is placeholder text and should be replaced with actual information about Dr. Irfan. Update the following:

1. Personal information (name, title, email, phone, etc.)
2. Research areas and interests
3. Academic background and positions
4. Publications and projects
5. Conferences and workshops
6. Contact details and FAQs

### Images

You need to add the following images to the `/public` directory:

1. `hero-bg.jpg` - Home page hero background
2. `research-bg.jpg` - Research Interests page header background
3. `academics-bg.jpg` - Academics page header background
4. `professional-bg.jpg` - Professional Experience page header background
5. `publications-bg.jpg` - Publications & Projects page header background
6. `conferences-bg.jpg` - Conferences & Workshops page header background
7. `contact-bg.jpg` - Contact page header background

### Styling

The website uses a green color scheme (#01bf71) as the primary color. You can customize the colors in each CSS file to match Dr. Irfan's preferences or institutional colors.

## Technologies Used

- React
- React Router
- CSS (modular approach with separate CSS files per component)
- Font Awesome (for icons)

## Responsive Design

The website is fully responsive and works well on all devices, from mobile phones to large desktop monitors.
